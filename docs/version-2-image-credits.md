## Version 2 image rules

- Do not alter the approved homepage/Explore composition to fit a photograph.
- Test every hero at desktop, tablet and phone crops; replace the photograph if
  the landmark or focal point fails rather than redesigning the card.
- Discover defaults to real photography.
- User memory photos remain original by default and can optionally use Photo
  Studio: Original / Enhance / Reimagine / Restore.
- The original user photo is never overwritten or deleted by an AI operation.
- Before public/commercial launch, re-check each source page and final production
  asset, and expose required attribution in the product's image credits.
